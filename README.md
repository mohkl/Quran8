# MUSHAF v1.0.1
تطبيق مصحف + أذكار + مسبحة، يعمل بدون إنترنت (PWA) ويُستضاف على GitHub Pages.

## النشر
1. أنشئ مستودعًا جديدًا على GitHub وارفع كل هذه الملفات (فرع `main`).
2. من Settings ← Pages ← Source اختر **GitHub Actions**.
3. بعد انتهاء الـ Action يظهر الرابط. افتحه من الجوال ← "إضافة إلى الشاشة الرئيسية".

## العمل بدون إنترنت
- نص القرآن والتفسير: يحمّلهما الـ Action داخل `data/quran.json` ويُخزَّنان تلقائيًا.
- الصوت (مشاري راشد العفاسي): زر ⬇ داخل كل سورة يحفظها على الجهاز.
